1.5 Стратегия «LLM-Router» — переключение моделей без переписывания кода
В коде делаешь один интерфейс и за ним прячешь нескольких провайдеров. Если один сломался — переключаешься на другой.


// Пример псевдокода
const router = new LLMRouter([
  { name: 'gigachat',     priority: 1, condition: 'private && ru' },
  { name: 'deepseek',     priority: 2, condition: 'general' },
  { name: 'pollinations', priority: 3, condition: 'fallback' },
]);
 
const response = await router.chat(messages, { task: 'solve_math' });
// → автоматически выберет лучший доступный провайдер
Преимущество: если у DeepSeek кончатся бесплатные токены — ты автоматически переключишься на GigaChat. А Pollinations — резерв на случай если оба упадут.

TalkingHead.js + Ready Player Me — 3D-аватар учителя с lip-sync.
MathJax — формулы на доске (рендерятся как текстура).
Yandex SpeechKit — TTS русским голосом (1M символов/мес бесплатно).

На старте — только профматан ЕГЭ, 30 ключевых тем. Уроки заранее написаны как JSON (текст + команды доски). На v2 — генерация уроков на лету.

2.2.3 Что происходит технически
Сценарий А — «Готовый урок»
Учитель (3D-аватар Ready Player Me) стоит у доски.
Из заранее подготовленного скрипта (текст + анимации доски) воспроизводится лекция:
TTS озвучивает текст голосом Yandex SpeechKit.
TalkingHead.js делает lip-sync (губы анимируются под звук).
Three.js рисует на доске поэтапно — теорема, чертёж, доказательство.
У ученика есть кнопки: пауза, перемотка, повтор части, изменение темпа (0.5x – 2x), субтитры.
В любой момент ученик может нажать «Спросить» → пишет/говорит вопрос → урок ставится на паузу → аватар отвечает в свободной форме (LLM генерит ответ налету) → продолжает урок с того же места.
Сценарий Б — «Спроси у ИИ»
Юзер не выбирает урок, а пишет: «Объясни мне теорему Виета».

LLM генерит структурированный план объяснения.
На лету для каждого шага:
Текст для TTS.
Команды для доски: что нарисовать (формула, график, чертёж).
Аватар в реалтайме «читает» свой свежесгенерированный сценарий и рисует.
2.2.4 Доска — что она умеет
Это самая интересная часть. Доска — интерактивный 3D-объект в Three.js. На ней может появляться:

Текст и формулы (LaTeX через MathJax → текстура на доске).
Чертежи — треугольники, окружности, графики функций. Рисуются «маркером»: видна анимация, как линия проводится.
3D-объекты — выезжающая из доски пирамида (для стереометрии). Можно вращать мышью, приближать/отдалять.
Шаги решения — задача появляется наверху, шаги по очереди ниже.
Подсветка — если учитель говорит про конкретную часть, она подсвечивается.
Юзер может:

Зум доски колёсиком/жестом.
Вращать камеру вокруг (видеть аудиторию с разных ракурсов).
Сделать скриншот доски для конспекта.
Скачать конспект урока в PDF (текст + чертежи).
2.2.5 Проигрыш ответов на вопросы
Когда юзер задаёт свой вопрос:

Аватар ставит лекцию на паузу с анимацией: «опускает» руку, поворачивается к камере.
Над его головой появляется индикатор «думает» (3 точки).
LLM (DeepSeek R1 для сложных или GigaChat для простых) генерит ответ + список действий с доской.
TTS озвучивает, аватар говорит, доска заполняется.
После ответа: «Возвращаемся к лекции?» → ученик кликает Да → продолжение.
2.2.6 Прогресс и геймификация
После каждого урока:

Тест из 3–5 задач — нужно набрать 60% чтобы тема считалась освоенной.
+опыт на аккаунт (уровень, лиги).
Ачивка за окончание темы.
На карте курса тема меняет цвет: 🔴 → 🟡 → ✅.
После 5 тем подряд → бонус: открывается «дуэль» — соревнование с другим учеником (асинхронно, на одной задаче).

2.2.7 Почему именно профматан и почему именно так
Профматан = самый болевой ЕГЭ для большинства школьников. 30+ баллов получают единицы.
Визуализация в матане критична — формулы, графики, чертежи. 3D-доска решает это лучше любого видео на YouTube.
«Нет учителя, который объяснит понятно» — главная боль регионов. У каждого ученика теперь есть «личный Савватеев».
Сегмент покупателей — родители, которые тратят 30–50к в месяц на репетиторов. Им продать 1990 ₽/мес — копейки.

3.2 Что НЕ скачивается «себе на комп»
Это важный момент, который ты упомянул.

Где живут данные:
Парсер (Cloudflare Worker) — запускается каждые 5 минут на серверах Cloudflare, парсит RSS Авито, кладёт в Cloudflare D1.
БД (Cloudflare D1 / Supabase) — хранится в облаке, не на твоём компе.
Бот (Cloudflare Worker / Yandex Cloud Function) — крутится в облаке, отвечает юзерам.
Юзер — видит только пуши и открывает оригинальные ссылки на Авито.
Что есть «у тебя»:
Только исходный код на GitHub (~3000 строк TypeScript).
Cloudflare аккаунт (бесплатный) с дашбордом.
Локально — только редактируешь код.
Юридически:
Парсинг публичных RSS Авито — серая зона, но рабочая (есть прецеденты, тысячи ботов это делают).
Не парсим за логином, не парсим личные данные продавцов.
В ToS говорим «пользователи получают агрегированные публичные данные».
Если Авито начнёт блокировать → переход на партнёрство (Авито Pro API) или работа через TG-каналы агрегаторов (легально).

3.5 Стратегия LLM в Авито-боте
Скам-чекер вызывается на КАЖДОМ найденном дешёвом лоте — это много запросов. Поэтому стратегия:


Объявление выглядит дёшево
       │
       ▼
[Простой rule-based фильтр]   — отсекает 80% спама без LLM
   • цена < 30% от медианы → почти точно скам
   • продавец < 7 дней + новичок → флаг
   • в описании WA/Telegram + срочность → флаг
       │
