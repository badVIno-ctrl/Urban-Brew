🎓 «ШколаГПТ» — ИИ-репетитор ЕГЭ
Боль и рынок
Час репетитора в Москве 2–4 тыс ₽, в год 150–400 тыс ₽ родителям.
Регионы — почти нет нормальных репов по информатике/профмату.
Школьник стесняется спросить учителя 50 раз. Боту — не стыдно.
TAM в РФ: ~8 млн школьников + 4 млн студентов = ~12 млн.
Конкуренты — кто есть и почему есть место
Школково (резидент Сколково, апрель 2026) — закрытый ИИ-помощник, только для своих учеников, без бота, UX «как кабинет».
Skyeng Vimbox — только английский.
Учи.ру — младшая школа, не ЕГЭ.
ChatGPT/GigaChat — не знают КИМы, ошибаются в формулах, школьники их юзают как костыль.
Foxford/Тетрика/MAXIMUM — живые занятия, дорого (3–10 тыс ₽/мес), не 24/7.
Незанятая ниша: ИИ-репетитор в Telegram + с личностью + знающий именно КИМы + с голосовыми объяснениями.

Главная фишка — «ИИ-репетитор с характером»
Не один безликий бот, а выбор наставника:

Марьиванна — строго, с укором (тем кому нужна дисциплина)
Брат Илья — на «ты», мемы, бро (парням, кринжовщикам)
Тренер Спартак — мотивирует, ставит цели (целеустремлённым)
Бабушка Зина — тёплая, поддерживающая (тревожным, выгорающим)
Профессор — сухо, академично (олимпиадникам, перфекционистам)
Один LLM-движок, разные промпты стиля.

7 ключевых фич
Фото задачи → разбор голосом персонажа (TTS Yandex SpeechKit), без сразу-ответа — наводящие вопросы.
Тренажёр под каждый тип задания (27 заданий КЕГЭ, 19 профмата, 27 русского).
Эмулятор полного ЕГЭ с балльной оценкой по схеме ФИПИ.
«Хочу понять, а не зубрить» — объяснение за чем стоит формула.
Дневник прогресса (стрики, уровни, лиги с друзьями).
Голосовая обратная связь — надиктовываешь решение, бот разбирает по шагам.
Родительский кабинет (видит стрики, не видит контент).
Технически
aiogram 3 + FastAPI + Celery + Redis
OCR: Yandex Vision + GigaChat Vision Pro (для формул и блок-схем).
Мозг: RAG на векторной БД (Qdrant) — банк ФИПИ за 5 лет + учебники Полякова/Ященко/Цыбулько → ИИ не выдумывает, а опирается на проверенные методики.
Голос: Yandex SpeechKit (на старте — стандартные голоса с SSML, потом кастомные за 50–150к ₽/голос).
Адаптив: Bayesian Knowledge Tracing (классика EdTech, без ИИ — чистая статистика).
LLM: YandexGPT 5 Pro / GigaChat MAX (обязательно российские по 152-ФЗ).

Реалистичный за год: 30к платящих, ARR ~200 млн ₽.
Оптимистичный за 2 года: 200к платящих, ARR ~1.2 млрд ₽.
GTM — главные каналы
Школьные TG-чаты (партизанский, через лидеров мнений в классе).
ЕГЭ-блогеры (100ballnik 500к подписчиков, ЕГЭ-матос).
Учителя как агенты (рефералка 10–20% с подписок).
VK + Дзен (контент-маркетинг разборов).
Партнёрства со школами (бесплатно «слабым», KPI школы — баллы).
MVP за 6–8 недель, бюджет 0 ₽ (одному) или ~400–600к (с командой).
🛒 «Авито-Бот» — ИИ-охотник за халявой
Боль и рынок
На Авито 3 млн новых объявлений в день, цены очень рандомные.
Уже есть мониторы (pilingator, AvitoFinder) — но они тупые: шлют всё подряд по фильтру, не знают где халява.
Никто на рынке РФ не делает ИИ-оценщика, который сам определяет «дёшево или нет».
Целевая аудитория
Сегмент	Размер	Готов платить
Перекупы (телефоны, авто, техника)	~50 тыс.	1–10 тыс ₽/мес
Дропшипперы / Авито-бизнес	~100 тыс.	1–10 тыс ₽/мес
Любители халявы (студенты)	миллионы	200–500 ₽/мес
Покупатели авто/недвиги (раз в год)	~3 млн	500–2000 ₽ разово
Коллекционеры (часы, винил, бренды)	~200 тыс.	500–2000 ₽/мес
Главное отличие от существующих
Они: «iPhone 14 в Москве до 40к» → шлёт всё. Мы: «Я слежу за iPhone 14 256GB» → ИИ сам строит модель цены → присылает только «35 000 ₽, на 28% дешевле рынка, продавец надёжный, фото не воровано».

6 ключевых фич
ИИ-оценка цены (XGBoost на признаках + эмбеддинги).
ИИ-проверка фото (Vision + reverse search — не воровано ли).
ИИ-проверка продавца (анализ профиля, рейтинг, история).
Узкие ниши (Rolex Submariner, BMW M5 E60, винил Beatles, PS5).
Авто-предложение (Premium: бот сам пишет «возьму за 33к, заберу сегодня»).
Дашборд для перекупов (воронка алертов → сделок → маржи).
Главный челлендж — где брать данные
Вариант	Плюс	Минус
Парсинг через прокси	Полный охват	Авито банит, серый юр.статус
RSS-выдача	Легально, публично	Только результаты поиска
Партнёрство с Авито	Чистый путь	6–12 мес переговоров
TG-каналы агрегаторов	Легально	Часть рынка
Рекомендация: для MVP — RSS + TG-каналы. На рост — официальное партнёрство.

⚠️ Юридически: не парсить за логином (273 УК РФ). RSS — серая, но рабочая зона. Авито в ToS запрещает, но прецеденты в судах смешанные.

Технически
Python + httpx + ротация прокси для парсинга.
Apache Kafka для потока объявлений.
TimescaleDB — история цен.
Pricing-модель: XGBoost / CatBoost на категорию + Sentence Transformers для эмбеддингов описаний. Обновление раз в неделю.
Скам-детектор: Vision-эмбеддинг → reverse image search Yandex; LLM-чекер описаний.
Триггер: actual_price < predicted × 0.85 И scam_score < 0.3 И seller_score > 0.5 → пуш за 30–90 секунд.
