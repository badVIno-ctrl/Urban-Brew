Как использовать

# Простейший вызов БЕЗ авторизации (для тестов и низкого трафика):
curl "https://text.pollinations.ai/Объясни%20теорему%20Пифагора%20простыми%20словами"
 
# Для прода — получаешь ключ на enter.pollinations.ai (бесплатно):
curl https://gen.pollinations.ai/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai",
    "messages": [{"role": "user", "content": "Привет!"}]
  }'

1.5 Стратегия «LLM-Router» — переключение моделей без переписывания кода
В коде делаешь один интерфейс и за ним прячешь нескольких провайдеров. Если один сломался — переключаешься на другой.


// Пример псевдокода
const router = new LLMRouter([
  { name: 'gigachat',     priority: 1, condition: 'private && ru' },
  { name: 'deepseek',     priority: 2, condition: 'general' },
  { name: 'pollinations', priority: 3, condition: 'fallback' },
]);
 
const response = await router.chat(messages, { task: 'solve_math' });
// → автоматически выберет лучший доступный провайдер
Преимущество: если у DeepSeek кончатся бесплатные токены — ты автоматически переключишься на GigaChat. А Pollinations — резерв на случай если оба упадут.


🎓 Онлайн-школа
Бот = простое решение задач. Юзер фоткает задачу → персонаж (Брат Илья / Профессор / Бабушка Зина) ведёт сократический диалог («что бросается в глаза?», «когда касание?»), даёт подсказки, не сразу ответ. Тренажёр по 19 типам профматана + дневник прогресса + недельный план.

Сайт = 3D-учитель в браузере. И это полностью реализуемо БЕСПЛАТНО, потому что есть готовая JS-библиотека TalkingHead — делает 3D-аватара с lip-sync прямо в браузере, поддерживает Ready Player Me модели, MIT лицензия.

Стек 3D-урока (всё бесплатно):

Three.js — 3D-сцена и интерактивная доска (зум, вращение).
TalkingHead.js + Ready Player Me — 3D-аватар учителя с lip-sync.
MathJax — формулы на доске (рендерятся как текстура).
Yandex SpeechKit — TTS русским голосом (1M символов/мес бесплатно).
DeepSeek/GigaChat — мозг (генерит сценарий + отвечает на вопросы).
Глазами юзера: заходит на сайт → выбирает тему «Теорема Пифагора» → 3D-аватар стоит у доски → озвучивает теорию → доска заполняется маркером (формулы, чертежи, графики 3D) → юзер может зумить доску, ставить паузу, спрашивать вопрос (аватар прерывается, отвечает, продолжает) → после урока тест из 5 задач → ачивка → следующая тема разблокируется.

На старте — только профматан ЕГЭ, 30 ключевых тем. Уроки заранее написаны как JSON (текст + команды доски). На v2 — генерация уроков на лету.



🛒 Авито-бот в TG
Главное: ничего не скачивается тебе на комп. Всё крутится в облаке (Cloudflare Workers + D1). У тебя локально только код. Юзер видит только пуши в TG.

Глазами юзера:

Создаёт подписку: «iPhone 14 256GB, Москва, Б/у, только хит» → бот мгновенно показывает текущую медиану рынка и сколько сейчас дешёвых.
Получает пуши: 🔥 «iPhone 14 256GB за 35 000 ₽ — на 22% ниже рынка. Продавец 4.8★, фото оригинальные. ✅ Не скам». Кнопки: открыть на Авито / написать продавцу.
Получает скам-сигналы: ⚠️ «60% ниже рынка, продавец 3 дня, фото нашлись на 4 сайтах».
Pro-фича: бот сам пишет продавцу первым: «Возьму за 33к, заберу сегодня».
Стата: «За месяц 47 халяв, экономия ~45к ₽».
Архитектура: CF Cron каждые 5 мин парсит RSS → дедупликация → rule-based фильтр (80% мусора отсекается без LLM) → Pollinations/DeepSeek проверяет на скам → пуш в Telegram. На бесплатных тарифах CF тащит до 10к юзеров.
